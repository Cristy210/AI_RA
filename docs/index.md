# AI Research Assistant

AI Research Assistant is a local Retrieval-Augmented Generation (RAG)
application for querying research papers using natural language.

The project combines:

- **MLX-LM** for local language model inference
- **Chroma** for vector storage and retrieval
- **LangChain** for the RAG pipeline
- **Streamlit** for the interactive interface
- **Model Context Protocol (MCP)** for exposing research tools and resources
